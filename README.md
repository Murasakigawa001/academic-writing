# academic-writing
Some skills that may be useful when revising papers.

## Skills

### condense-to-limit

把已成型的长稿压缩到字数、词数或页数上限，并把可以迁移的内容整理到附录或补充材料中。

- 技能目录：[skills/condense-to-limit](/workspaces/academic-writing/skills/condense-to-limit)
- 可下载压缩包：[releases/condense-to-limit-v1.1.0.zip](/workspaces/academic-writing/releases/condense-to-limit-v1.1.0.zip)
- 单文件安装器：[install_condense_to_limit_v1_1_0.py](/workspaces/academic-writing/install_condense_to_limit_v1_1_0.py)

直接使用技能目录：

```bash
ima_skill_create -d ./skills/condense-to-limit
```

或从压缩包安装：

```bash
python3 install_condense_to_limit_v1_1_0.py --target <skill-root> --force
```

详见 [skills/condense-to-limit/INSTALL.md](/workspaces/academic-writing/skills/condense-to-limit/INSTALL.md)。
